## Часть 1. Геометрические фигуры

Общим родителем выступает абстрактный класс `Shape`. В нем находятся цвет и признак заливки. Поля имеют доступ `protected`, поэтому доступны наследникам. Для внешнего обращения есть геттеры и сеттеры.

Площадь и периметр объявлены абстрактными методами `getArea()` и `getPerimeter()`. Общая фигура не задает конкретную формулу, это делают наследники.

| Класс | Что хранит | Как считает |
| --- | --- | --- |
| `Circle` | Радиус | Площадь `πr²`, периметр `2πr` |
| `Rectangle` | Ширину и длину | Площадь `width * length`, периметр `2 * (width + length)` |
| `Square` | Равные стороны через поля Rectangle | Использует формулы родителя при равных ширине и длине |

Квадрат наследуется от прямоугольника. Его `setSide()`, `setWidth()` и `setLength()` сохраняют равенство сторон. Поэтому изменить только одну сторону квадрата нельзя.

### Какие объекты создаются

В `TestShape` создаются круг радиусом `3`, прямоугольник со сторонами `4` и `7`, квадрат со стороной `5`. Все объекты помещаются в массив `Shape[]`.

Программа проходит по массиву и выводит описание, площадь, периметр, цвет и заливку. Например, площадь прямоугольника равна `28`, периметр равен `22`. У квадрата площадь равна `25`, периметр равен `20`.

Тип ссылки в цикле общий, но метод вызывается у конкретного объекта. Такое поведение является полиморфизмом.

### Почему часть строк из методички не работает

Создать `new Shape()` невозможно, поскольку класс абстрактный. Также через ссылку `Shape` нельзя напрямую вызвать `getRadius()`, `getLength()` или `getSide()`: этих методов нет в описании общего типа.

В демонстрации сначала выполняется приведение к подходящему классу, затем вызывается его метод. Например, радиус доступен после приведения к `Circle`. У ссылки `Rectangle` нет `getSide()`, поэтому для него требуется приведение к `Square`.

Приведение не создает новую фигуру и не изменяет старую. Если указать тип, которому объект не соответствует, возникнет `ClassCastException`.

## Часть 2. Движущиеся объекты

Интерфейс `Movable` задает четыре действия: движение вверх, вниз, влево и вправо. Интерфейс не хранит положение объектов, он определяет доступные действия.

`MovablePoint` реализует эти методы и хранит координаты вместе со скоростями по осям. При движении координата изменяется на соответствующее значение скорости. Вверх означает уменьшение `y`, вниз означает увеличение `y`.

`MovableCircle` состоит из радиуса и точки центра. При движении круга перемещается его центр. `MovableRectangle` содержит две точки, описывающие противоположные углы. Команда движения применяется к обеим точкам.

### Как сохраняется форма прямоугольника

Метод `hasSameSpeed()` сравнивает скорости углов по двум осям. Если скорости не совпадают, конструктор отклоняет создание объекта. Иначе углы при движении смещаются одинаково, а размеры сохраняются. Переданные точки копируются, поэтому внешние изменения исходных точек не влияют на прямоугольник.

В `TestMovable` создаются точка, круг радиусом `4` и прямоугольник с углами `(2, 3)` и `(14, 11)`. Они обрабатываются через массив `Movable[]`. После движений вверх, вправо, вниз и влево координаты возвращаются к исходным. Отдельный пример проверяет отказ при разных скоростях углов.

## Как запустить

Проект рассчитан на JDK 17 или новее. В IntelliJ IDEA нужно открыть папку этой работы, выбрать JDK и при необходимости отметить `src` как Sources Root. Затем запустить `main` нужного класса.

Для сборки из терминала используется `sh build.sh` в Linux или `build.bat` в Windows. Скомпилированные классы появляются в `out`.

```bash
java -cp out edu.mirea.pr3.shapes.TestShape
java -cp out edu.mirea.pr3.movable.TestMovable
```
